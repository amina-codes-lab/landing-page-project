# AM Estates — Real Estate Landing Page

A responsive real estate landing page built using HTML, CSS and JavaScript.

## Features

- Responsive navigation bar
- About and Services sections
- Client Testimonials
- Footer with social media links
- Smooth scrolling

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome (Icons)

## Purpose

This project was created as an internship task to practice frontend web development skills.
